# מוכנות לפרודקשן — מה נעשה, מה נמדד, מה עוד חסר

> עודכן: **2026-08-31** · משלים את [`testing.md`](testing.md) (איך בודקים) ואת [`methodology.md`](methodology.md) (הנתונים)

## אמינות וקריסות

- **ErrorBoundary בשורש** — שגיאת רינדור/JS מציגה מסך התאוששות דו-לשוני עם "נסה שוב" (re-mount), במקום קריסה נטיבית. הנתונים בדיסק לא נפגעים.
- **חיטוי מלא של ה-store בטעינה** (`restore()`): טיפוסים, טווחים (גיל ≤130, משקל ≤500, כמות 0.5–999), ברירות מחדל לכל שדה. JSON פגום → אתחול נקי במקום קריסה.
- **המנוע חסין לנתונים עוינים**: רשומות עם `t`/`q` לא-סופיים מדולגות; אין נתיב שמחזיר NaN (מכוסה בטסט).
- **Android back** מטופל בכל שכבות ה-UI; מקש חוזר לא מפיל את האפליקציה בטעות.
- **monkey storm** (5,000 אירועי קלט אקראיים) חלק מסוללת `e2e/stress.sh` — נכשל על כל CRASH/ANR.

## ביצועים ומשאבים

- **תקציב מנוע נמדד בטסט**: יומן של 10,000 רישומים (~48 יממות שימוש כבד) — בניית מנוע + דגימת גרף מלאה + כל קריאות האריחים **<150ms**; מחזור steady-state **<80ms** (`engine.hardening.test.ts`).
- **אופק ב-`prep()`**: רישומים שמעבר לאופק האנליטי שלהם (תרומה 0 מתמטית) לא נכנסים ללולאה החמה — יומן של חודשים לא מאט את הרינדור. מאומת bit-identical מול ה-golden.
- **קונטקסט ממו-איזד**; ספארקליינים ורינדור גרף נבנים מדגימות חד-פעמיות למחזור.
- **R8 minify + resource shrinking** פעילים ב-release ‏(`android.enableMinifyInReleaseBuilds=true`); Hermes + New Architecture פעילים. APK אוניברסלי (4 ABI) ‏~70MB; ל-Play מגישים **AAB** — ההורדה בפועל קטנה משמעותית.

## אנרגיה

- **שעון אחד** (30 שנ׳) שרץ רק כשהאפליקציה בחזית; ברקע — כלום (אין wakelocks, אין טיימרים). חזרה לחזית ⇒ re-clock מיידי.
- טיימר ה-15 שנ׳ של גיליון הרישום רץ רק כשהגיליון פתוח.
- אנימציות הספירה-לאחור מצוירות ב-SVG — בלי re-layout נטיבי בכל פריים.
- **מעקב זיכרון** בסוללת העומס: דגימת PSS לאורך 10 מחזורי UI כבדים; כשל אוטומטי על צמיחה >40% (דליפה).

## פרטיות כערך-על (חוק 4) — אכיפה טכנית

- `android:allowBackup="false"` — היומן לא עולה לגיבוי הענן של גוגל (plugin `withAndroidTweaks`).
- אין הרשאות מעבר ל-INTERNET (של ה-runtime); אין cleartext traffic.
- הרשת: רק תקציר `stateSummary()` ליועץ, ורק כששואלים. תוכן התקציר מפורט למשתמש בהגדרות ומוגדר ב-[`ai-advisor.md`](ai-advisor.md) (החלטת 2026-08-31: כולל גיל/מין/משקל/גובה/תרופות; בלי שם/מזהה/היסטוריה).

## מה עוד חסר לשחרור אמיתי (לא ניתן להשלמה מכאן)

| פער | מי מחליט/מספק |
|---|---|
| **חתימת release** — כרגע ה-release חתום ב-debug keystore של התבנית. נדרש keystore אמיתי (או Play App Signing) | בעל המוצר — יצירת מפתח וסודות |
| **proxy ה-AI** ‏(`EXPO_PUBLIC_AI_PROXY`) + שכבת הסירוב הדטרמיניסטית | פריסה לשרת; מפתח API |
| iOS — לא נבנה ולא נבדק בפרויקט זה | דורש macOS signing + מכשיר/סימולטור |
| Local Notifications ("החלון נסגר בעוד 20 דק׳") | פיצ'ר עתידי (docs/stack.md) |
| Crash reporting מרוחק | **החלטה מוצרית** — עומד בסתירה ל"אפס טלמטריה"; כרגע בכוונה אין |

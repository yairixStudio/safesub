## הזרימות (`app/e2e/`)

| # | תרחיש |
|---|---|
| 01 | הפעלה ראשונה: עברית כברירת מחדל, החלפה לאנגלית וחזרה בדרופדאון, חמשת המסכים, גריד ריק |
| 02 | חיפוש → הוספה → רישום עם תת-סוג וכמות → אריח פעיל `(1)` → יומן |
| 03 | אלכוהול פעיל + קטמין: דגל **מסוכן** בגיליון, ו"שילוב פעיל" בקריאת המצב |
| 04 | עריכת רישום מהיומן (הזזה אחורה בזמן) ומחיקה |
| 05 | הגדרות: בהיר/כהה, אנגלית/עברית, כפתור חזרה בשני הכיוונים |
| 06 | פרופיל עם ליתיום → רישום LSD מעלה דגל מהפרופיל; ראשי תיבות בכפתור |
| 07 | לחיצה ארוכה → מסך למידה (בסיס הנתונים) → הסרה מהרשימה |
| 08 | חומר שלא בקטלוג → חומר מותאם |
| 09 | היועץ: שאלה מהגיליון + שאלה חופשית, תשובה בשפה הפעילה |
| 10 | מחיקת כל הנתונים (שתי לחיצות) → אונבורדינג → רשימה ריקה |
| 11 | רישום רטרואקטיבי, הריגת האפליקציה והפעלה מחדש — הכל נשמר |

צילומי מסך ולוגים: `test-artifacts/e2e/<timestamp>/`.

## דרישות סביבה

JDK 17, Android SDK (API 34), AVD, Maestro. `e2e/run.sh` מגדיר `JAVA_HOME`/`ANDROID_HOME` לברירות המחדל של Homebrew ומסתיר את `flutter` מ-PATH (Maestro נתקע עליו).
